# Fusion Pixel fonts / 缝合像素字体

Unmodified Simplified Chinese proportional OTFs, 8px and 10px, from [Fusion Pixel release 2026.11.10](https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.11.10), by TakWolf and the upstream contributors credited in the bundled licenses. Runtime sizes are native integer multiples; English UI retains Beatspell's original hand-drawn glyphs.

These fonts are distributed under SIL Open Font License 1.1. Original release notices and component licenses are preserved in `licenses-8px/` and `licenses-10px/`. The portable game also ships these notices in its `FONT_LICENSES/` folder. No font modifications or renaming were made.
