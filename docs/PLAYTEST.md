# Beatspell v0.3.0 试玩说明

## 开始前

请先不要阅读术式说明，只根据标题和游戏内画面开始。建议使用有线耳机或电脑扬声器；如果明显感觉声音与画面错位，按 `C` 完成一次校准。

启动 `Launch Beatspell.cmd`，完整游玩到胜利或失败。第一次结束后可以查看下面的操作表，再玩第二次。

| 输入 | 功能 |
|---|---|
| `D/F` | 动作 |
| `J/K` | 结束术式；标题界面开始 |
| `P` | 暂停 |
| `R` | 重开本局 |
| `C` | 音频校准 |
| `T` | 标题进入无伤害练习 |
| `T` | 课程完成后切换无伤害防御训练 |
| `H` | 术式手册 |
| `O` | 音乐/音效/震动/全屏设置，方向键调整 |
| `Esc` | 回标题；标题界面退出 |

## 试玩反馈

请记录两次尝试的结算等级与平均偏差，然后回答：

1. 第一次是否知道什么时候可以开始输入？
2. 是否能从圆环看出自己按快了还是按慢了？
3. 第几次尝试学会 FLARE、AEGIS 和 MEND？
4. 能否只靠声音区分标准、切分和 Rush 三种 Boss 预警？
5. Boss 攻击前是否有足够时间准备 AEGIS？
6. 哪一次失败最像是游戏没有解释清楚，而不是自己按错？
7. 哪个画面或声音最影响注意力？
8. 如果只能修改一个地方，你希望改什么？
9. 精准格挡、破防和共鸣奖励是否容易理解？你是否愿意为了破防选择防守？
