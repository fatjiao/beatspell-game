# v0.7 棱镜内容版本

本批响应“大批量继续开发”，在 v0.6 的三种同 Boss 规则上新增真正不同的第二位 Boss，并完成训练、战绩与中断保护配套。保留连续全局四拍环、120 BPM、任意整拍起手和真实输入位置。

## 范围与实施

1. 独立规则模块新增 Prism：72 HP、每两小节伤害 2、回声/反拍预警交替；四小节护甲/开放核心轮换，火球最终伤害减/加 1，最低 1。
2. 战斗模型支持每场最大生命及火球环境修正，场景以完成术式时的小节计算姿态。与三格破防和四连击共鸣分别处理。
3. 原创 AI 生成棱镜守卫透明像素素材，游戏内像素采样、轨道晶片与状态条；增加三枚可重建晶体音效。
4. 专项防御训练增至五种，结算战绩增至四种挑战；新增通关、A 级通关、S 级通关勋章，兼容旧存档。
5. 失焦自动暂停；恢复前三拍准备，音乐与指令保持冻结。取消恢复、打开手册/设置、重开与重复失焦都需有确定行为。
6. 25 组单元测试与三套真实场景流程；中英文实机截图检查；便携 ZIP 启动检查。
7. 同批维护中英文图文玩法、14 图、在线原 Page、CHANGELOG 与接力指南，提交并推送公开仓库。

## 约束

- 不新增下落音符或要求从顶部起手，不改变原三模式的伤害与时间窗口。
- 开放核心属于 Boss 姿态，与格挡触发的弱点独立；伤害实际值必须记入统计。
- 旧存档最高评级可能来自败局，不据此授予高阶通关勋章。
- 三拍恢复不重置音乐位置；恢复提示音按暂停相位排列。
- 自动化不能替代真实设备听感测试。本版仍是内部 Demo，非 Steam 正式发行。
