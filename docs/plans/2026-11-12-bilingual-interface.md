# v0.5.0 中英文界面实施计划

目标：在现有 320×180 像素游戏中提供完整中文和英文，可随时在设置切换，保留节拍、战斗与练习状态。

1. 集中管理文案与格式参数；模型继续保存语言无关标识，反馈在绘制时翻译。
2. 设置新增自动／中文／English，自动按系统语言解析，旧设置自动迁移，偏好本地保存。
3. 内置 Fusion Pixel 简体像素字体，附完整上游授权；英文保留现有字模。
4. 覆盖标题、战斗、阶段、术式、设置、手册、校准、结算与防御报告；检查中英文布局。
5. 增加设置迁移、词条与字体覆盖、格式参数、热切换和重启持久化验证；运行现有回归和导出检查。
6. 更新公开中英文玩法指南、语言设置配图、在线 Page、接力文档和变更记录，生成便携包并推送仓库。

验收：所有当前游戏界面可切换语言，无缺字和重叠；语言切换不重置战斗；独立测试设置不覆盖玩家设置。

完成记录（2026-11-12）：22 组测试及扩展场景流程通过；已检查中英文关键页面和校准结果。v0.5.0 便携包完成导出与启动检查，字体授权逐文件核对。中英文指南、十张图、在线 Page 的 122 个正文块及图片引用已核对一致。
