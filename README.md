# One Person Band Demo

《一个人的乐队》轻音游 Demo。当前版本包含地下通道舞台、四键乐器切换、电子流行分轨、节拍判定、音频校准和宽松失败机制。

## 运行

直接双击 `启动游戏.cmd`。这个启动器不依赖 PowerShell 执行策略；如果启动失败，窗口会保留并显示错误。

也可以在 PowerShell 中执行：

```powershell
& '.tools\godot\Godot_v4.7.2-stable_win64.exe' --path .
```

## 操作

- `D`：电子鼓
- `F`：贝斯
- `J`：合成器
- `K`：主旋律
- `Tab`：切换舞台视图 / 四轨调试视图
- `P`：暂停 / 继续
- `R`：立即重新开始；结算后再演奏一次
- `C`：打开音频延迟校准

屏幕下沿是一条紧凑、持续流动的五线谱：鼓、贝斯、合成器和主旋律共享谱面，以不同音高位置、颜色与音符形态区分，并从右向左进入同一根判定线。D/F/J/K 只在左侧小图例及音符临近时显示；最终合奏会把四种声部交错写进同一条谱。鼓点仍会驱动地面波纹，其他声部逐层点亮舞台并吸引路人；曲目结束后显示成绩、准确率和评级。

首次使用蓝牙耳机或更换音频设备后，建议按 `C` 进入校准，跟随节拍按八次 `D`，再按 Enter 保存。
